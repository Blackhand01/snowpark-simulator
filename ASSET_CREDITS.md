# Asset provenance

## Geometry and images

Terrain, mountains, rail, supports, athlete, armature, clothing, skis, and equipment are generated by the project scripts. No external human model is distributed.

Images under `docs/images/` are synthetic renders of the Blender scene. The GIF comes exclusively from the synthetic motion preview and contains no real footage. Photographic and video references used during development are neither distributed nor used as character textures.

## Snow textures

- **Snow 01**, by **Rob Tuytel**, [Poly Haven](https://polyhaven.com/a/snow_01).
- License: **CC0**, documented on the [Poly Haven license page](https://polyhaven.com/license).
- Included files: diffuse, bump, and roughness PNG maps at 1K, 1024 × 1024, totaling 2,826,732 bytes.
- Individual download URLs, file sizes, and SHA-256 hashes: [manifest.json](assets/polyhaven/snow_01/1k/manifest.json).

The material uses these maps for color, roughness, and shader surface detail; the groomed snow grooves are procedural.

Blender, FFmpeg, Python libraries, and Brush are not distributed with this repository and retain their respective licenses. Brush v0.3.0 is an optional backend licensed under Apache-2.0.

The textures' CC0 license does not automatically apply to the project code or other content.
